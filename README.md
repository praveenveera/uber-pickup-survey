# Pickup Story — Hyderabad Survey

An independent student product-management research survey about the experience of finding your driver or rider after an Uber-style booking in Hyderabad. **Not affiliated with or run by Uber.**

Live app: https://praveenveera.github.io/uber-pickup-survey/

- Mobile-first, single-question-at-a-time flow
- English / Telugu / Hindi, switchable at any time
- Answers are anonymous unless a respondent opts into a follow-up call
- Responses are stored in a private Google Sheet the author controls — see `apps-script.gs` for the backend

Source and full write-up live in the author's private coursework repository; this repo exists only to host the public-facing survey.
